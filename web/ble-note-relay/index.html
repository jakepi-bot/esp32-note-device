Hermes note relay

Takes the voice notes waiting on the e-paper gadget over Bluetooth and posts them to Hermes. Works with no Wi-Fi on the device, only Bluetooth between it and this phone.

First time with this phone: the gadget asks before it trusts a new phone. Press Pair on the gadget (Settings → Phone app), tap Allow on its screen when it names this phone, then tap Connect here. The gadget then shows a 6-digit code and iOS shows the same one: tap Pair only if they match.
